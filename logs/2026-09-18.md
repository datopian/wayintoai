# 2026-09-18 Jev Brings AI Decisions Into Software

## [[typesafe-jev]] — TypeSafe introduces System One

TypeSafe has announced Jev, a model for fast, typed decisions with probabilities, opening up an interesting approach to AI inside ordinary software. Our [featured write-up](../posts/2026-09-18-typesafe-jev-system-one.md) examines the interface, performance claims, and why type safety does not guarantee correct decisions.

## [[bb]] — An IDE that builds itself

bb is a local-first, MIT-licensed agent workbench that runs several coding agents on their existing subscriptions and can extend itself through plugins agents build. Its [product post](https://getbb.app/blog/an-agentic-ide-that-builds-itself) makes the case especially well: one install can become a task system, tiled thread manager, code-review automation, markdown vault, or more.
