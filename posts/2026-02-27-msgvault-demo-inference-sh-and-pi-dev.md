## [msgvault](https://ailearnedtoday.com/ref/msgvault) - Local-first Email Archive

**Wes McKinney** (pandas/Arrow creator) built **msgvault**: local-first email archive powered by **DuckDB** with **MCP** server for AI agent integration. Handles 20 years of Gmail (2M emails, 150K attachments) in a single Go binary.

![](/assets/msgvault-demo-inference-sh-and-pi-dev-2026-02-27-cd48.png)


## [inference.sh](https://ailearnedtoday.com/ref/inference-sh) - The Agent Runtime

Production runtime platform for AI agents. Provides durable execution, tool orchestration (150+ apps), observability, and agent primitives (deep-agents, human-in-the-loop, widgets). Pay-per-execution, self-hostable, integrates with x402 payment protocol.

![](/assets/msgvault-demo-inference-sh-and-pi-dev-2026-02-27-b463.png)

## [pi.dev](https://ailearnedtoday.com/ref/pi.dev) - New Home for pi Coding Agent

\[Feb 4th!\] Mario Zechner announced pi coding agent now has official home at <https://pi.dev/> (domain donated by exe.dev). Minimal, extensible terminal coding harness - build your workflow with TypeScript extensions, skills, packages. 15+ providers, tree-structured sessions.

![](/assets/msgvault-demo-inference-sh-and-pi-dev-2026-02-27-de8b.png)
